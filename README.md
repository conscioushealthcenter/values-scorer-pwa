# Values-Aligned Social Media Scorer PWA

A privacy-first Progressive Web App that helps users build awareness around their social media consumption and steer their feeds toward their personal values.

## 📱 Install Instructions

**iPhone (Safari):**
1. Open this page in Safari
2. Tap Share button → Add to Home Screen

**Android (Chrome):**  
1. Open this page in Chrome
2. Tap "Install app" banner or Chrome menu → Add to Home screen

## ✨ Features
- Local-first (your data stays on your device)
- Works offline after install
- 10-value assessment framework
- Ready for AI-powered content scoring

Built with TypeScript + React + Vite as a PWA.
